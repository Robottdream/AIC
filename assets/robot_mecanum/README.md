# 圆形底盘、四全向轮与机械臂回转座（2026-10-03）

当前为用户最新要求的圆形全向车型。目录及部分ROS标识保留mecanum作为兼容名称，
轮子已改为径向轮轴、轮缘切向被动滚子的普通全向轮。

- `robot_round_omni.blend`：米制可编辑Blender模型。
- `robot_mecanum.blend`：同一新版模型的兼容文件名。
- `build_model.py`：重建模型及四视角图片，`-- --check-only` 可跳过渲染。
- `export_meshes.py`：生成轮关节本地坐标STL与视觉xacro。
- 四张PNG为当前效果图；`geometry_checks.json`记录几何尺寸。

主体直径480mm、高100mm；轮半径75mm，中心 `(±195, ±195, 75)` mm。
每轮10个切向被动滚子。固定总成最大平面半径315.8mm，导航使用半径325mm
的24边形包络。轮支撑碰撞柱与圆形主体有约5.8mm径向间隙。
机械臂安装面260mm，回转范围±180°；左右雷达中心 `(0, ±225, 194)` mm。
前相机位置保留，雷达总成位于镜头平面后134mm。

测试系统 `/home/polarbear/ws_aic_mecanum_20261002` 已接入新版，运行
`bash ros_round_omni_start.sh start --headless`。旧 `/home/polarbear/ws_aic` 保留，
二者不能同时启动。接近目标时保持底盘朝向，由回转座预转；到点根据真实位姿
复核对准后才弯臂。三件连续任务通过，车体最大偏转0.030°。

详见 `docs/round-omni-20261003.md`。底盘仍为理想速度驱动，吸附是虚拟连接；
不证明真实滚子牵引、接触抓取或所有动态环境安全。带货包络仍需纳入三维避障。
