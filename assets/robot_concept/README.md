# 小车结构概念模型

本文件夹保留 Blender 审阅稿；经用户确认，结构已接入 Gazebo 默认机器人。验证记录见 `/mnt/e/workspace/AIC/log/robot-concept-integration/report.md`。

## 文件

- `robot_concept.blend`：米制、分部件模型，含四个相机和摄影棚。
- `front_perspective.png` / `rear_perspective.png` / `top.png` / `side.png`：四视角效果图。
- `build_model.py`：可重复生成模型的 Blender Python 脚本。
- `arm_reference.urdf`：由现有 `arm.xacro` 展开的尺寸参考快照。
- `geometry_checks.json`：外廓、接地高度和雷达间隙检查结果。

坐标为 X 向前、Y 向左、Z 向上，地面为 Z=0。驱动轮对象原点位于转轴中心，轮轴沿 Y。ROBOT 集合为新车结构，ARM 集合为现有机械臂几何参考，STUDIO 集合仅用于展示。

## 几何检查与设计说明

- 轮胎内侧与底盘侧面相距 2 mm；主体的圆角只切除材料，不扩大外廓。此间隙仅为概念尺寸，制造公差和悬架运动尚未评估。
- 两驱动轮和前后球形支撑轮最低点均为 Z=0，底盘底面为 Z=6 cm。支撑轮安装件与底盘、轮毂与轮胎、机械臂关节的连接区域存在设计接触或重叠，不代表可直接用于物理碰撞模型。
- 机械臂安装板居中，13×13 cm；原机械臂底座为 10×10 cm。参考模型保留原 URDF 连杆尺寸和关节坐标，展示一个示意运输姿态，不代表已验证的收臂轨迹。
- 当前姿态机械臂向前超出底盘约 5.1 cm；整车导航外廓不能仅按底盘长宽设置，后续须测收臂和携货外廓。
- 后置雷达扫描平面为 Z=66 cm，高于本姿态机械臂最高点约 4.2 cm；支架在扫描平面以下。抬高雷达可能漏检低矮物块，接入前必须评估低位测距补充方案与全关节活动范围。
- 摄像头位于前部，保留原中央机械臂位置。没有重新设计机械臂自由度，也没有赋予模型质量、惯量、驱动力或控制接口。

已运行 Gazebo 导航抓放测试；尚未系统验证重心稳定性、全部抓取工作空间和各关节姿态的碰撞扫掠。缩窄轮距可能降低侧向稳定性，不能仅凭本模型认定墙角卡顿已经解决。

## 仿真接入

STL 按部件和材质导出到 `src/yzbot/mybot_description/meshes/concept/`。URDF 使用简化碰撞体，修正底盘和支撑球惯量，保留原质量、驱动扭矩、速度和机械臂控制接口。低位 `/scan` 继续用于导航，高位 `/scan_high` 提供补充观测，未融合进代价地图。

`export_meshes.py` 可重复导出网格；`integrate_model.py` 是首次迁移记录，不应在已迁移的源码上重复执行。启动仍使用项目一键脚本。

## 重新生成

在安装 Blender 的 Windows 环境，将下述脚本路径映射到同一文件后，通过 Blender `--background --python` 执行：

`/mnt/e/workspace/AIC/assets/robot_concept/build_model.py`

脚本重建本文件夹内的模型与渲染，不操作已打开的 Blender 场景。ROS 项目运行仍只在 WSL 中进行。
