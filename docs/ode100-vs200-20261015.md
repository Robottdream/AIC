# ODE100 / 200空场对照与测试脚本（2026-10-15）

本次只对比 `contact_max_correcting_vel` 的100与200，没有改变正式导航2.2 m/s档位。空场直行与3.0 m/s、2 rad/s圆弧均通过实际平滑器执行，不发Nav2路径跟随目标，也不执行五件搬运。

## 对照条件

原始记录：`/home/polarbear/.local/share/aic-runs/20261015-ode100-vs200/`。

顺序100→200→200→100，四次独立冷启动，每次直行和圆弧各一次，共八项输入核验通过。模型描述、导航配置、任务配置哈希一致；世界文件归一化ODE值和采样文件路径后字节一致。原生接口读取实际ODE值，与请求一致。原生JSON采样无坏行，采样间隔检查通过。

驱动轮转矩1000 Nm；驱动轮和地面两个方向摩擦系数1；两驱轮半径0.065 m、轮距0.53 m。线加速3.5、减速5.0 m/s²；角加减速10 rad/s²，平滑器角速度上限4 rad/s。原生采样约100 Hz。

每项之前零速0.8秒、重置车体到原点且速度清零、稳定0.7秒；目标保持3.2仿真秒，停车观察2.2仿真秒。统计窗口为请求停车前0.5至0.1秒，约0.4秒。异常圆弧持续变化，下表不能叫稳态速度。窗口依试验各自实际动作时间截取，没有按某一图中外观选点。

## 八项对照结果

| 指标 | ODE100 | ODE200 |
|---|---:|---:|
| 直行后段前向速度，两次均值 m/s | 2.999983 | 2.999983 |
| 圆弧后段前向速度，两次均值 m/s | 0.613311 | 0.575962 |
| 圆弧后段角速度，两次均值 rad/s | 5.645137 | 5.764822 |
| 圆弧后段角速度两次范围 rad/s | 5.528789–5.761486 | 5.590703–5.938941 |
| 圆弧最大角速度，含停车 rad/s | 8.735312 | 8.934952 |
| 圆弧最大横滚/俯仰角 ° | 0.060246 | 0.059568 |

两种设置下，圆弧左轮约38.0、右轮约54.3076 rad/s；运动学换算约为3.0 m/s和2.0 rad/s。但实际车身轨迹都向内收缩成螺旋，角速度持续超过目标，前向速度下降。世界姿态偏航差分与原生角速度的平均绝对差约0.006 rad/s，远小于异常幅度。

四条响应曲线接近，两组范围重叠，没有观察到100消除异常或200明显改善运动响应。小样本且输入起始相位略不同，不作统计显著性结论，也不能概括为所有工况中ODE100和200完全等效。当前证据不支持“只有把100改成200才导致这次异常”。

轮速到位但车身运动不满足无滑移换算，提示继续检查接触/侧向摩擦/动力学约束；尚未隔离唯一根因，不能直接判定Gazebo本身有缺陷。倾角很小，不支持明显倾斜导致失效；没有逐轮接触力，不能据此证明始终正常接地。
