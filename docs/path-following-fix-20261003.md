## 问题与实现

门口现场位置约(2.402,-1.446)，左右真实雷达点距车中心最近1.384/0.533m，最终保护clear；速度链各段约0.025m/s。DWB停止、沿路径微动评分约25.23，预测没有拒绝这些候选。原PathDist/GoalDist按候选终点评分，既能把弧线端点附近的直线弦当作好候选，也会因两种评分抵消而不再前进。截图本身不能证明发生了实体接触，本轮没有捕获Gazebo接触传感器证据。

新增 `PathFollowCritic`，替代新车型的末端PathDist/GoalDist：

- 按有序路径线段投影当前位置，沿路径寻找前方0.65m目标，比较候选在0.6s位置与该目标的距离。
- 候选前0.6s偏离路径超过0.12m时拒绝；若起点已经偏离，则允许原偏离+0.03m，使车辆能够回到路径。
- 对完整1.8s候选所有采样点计算线段距离，软代价为0.5×平均偏离+0.25×最大偏离，再加上述前瞻目标距离，权重24。短前缀用于约束实际执行，长预测保持软评分，因为DWB常速度候选本身不会弯曲，真实控制器每50ms重新选择速度。
- 原FineOmni低速候选、静态足印碰撞拒绝、已知障碍逐时刻预测、Collision Monitor和最终雷达/命令/位姿失联停车保留。没有降低0.405m NearStop，1.00m/s合速度上限保持。

首版长预测软代价使用2×平均+最大偏离，虽然通过了原门口，但在放置点前约0.273m的短弯曲尾部停止。记录该现场路径后降低长预测软权重，并加入真实DWB闭环短曲尾回归。该中间失败未计作最终成功。
