# 车速试验记录（2026-09-30）

为缩短比赛任务时间，在 WSL2 的 Gazebo 仿真中测试了两档直行速度。正式配置保留 0.58 m/s；更快的参数没有作为默认值上传。

## 测试参数

Nav2 DWB 原本允许 0.8 m/s，但速度平滑器把基线输出限制在 0.58 m/s。第一档试验把 DWB 和速度平滑器都设为 0.8 m/s，并提高线加速度到 0.55 m/s²、制动减速度到 0.8 m/s²。轮子、扭矩、角速度、地图、导航包络和机械臂配置保持不变。

第二档将线速度上限降到 0.7 m/s，加速度恢复 0.35 m/s²，DWB 制动减速度设为 0.65 m/s²。速度平滑器保留更强的 -2.5 m/s² 紧急制动限制。

## 结果

| 配置 | 蓝块→B 首件结果 | 观察 |
| --- | ---: | --- |
| 0.58 m/s 基线 | 40.88 秒，成功 | 第四件红块→C 导航失败；体检报告定位与规划器位姿相差 8.47 m，触发 Nav2 自愈。因此基线未完成六件任务 |
| 0.8 m/s | 53.99 秒，失败 | 到同一蓝块抓取点从 15.83 秒降至 11.48 秒；返程导航失败，随后 Gazebo 真值显示车身严重倾斜（Z=0.257 m，roll=1.061 rad） |
| 0.7 m/s | 216.72 秒，成功 | 抓取与放置闭环完成；本轮 WSL/Gazebo 墙钟运行明显变慢，无法作为公平速度对照，也没有完成整组任务 |

动态障碍物位置、主控选块、导航恢复和仿真运行负载会影响耗时。0.8 m/s 的首段加速收益不足以抵消返程失败风险；0.7 m/s 的单次慢速运行也没有证明提速。故正式 Nav2 配置维持 0.58 m/s，未宣称车速优化提高了成绩。后续应在负载稳定、相同物块与路线下重复对照，并记录仿真真值和整组完成率，再决定是否采用更高速度。
