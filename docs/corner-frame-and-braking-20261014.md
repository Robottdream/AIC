# 墙角坐标、制动轨迹与贴墙选路检修（2026-10-14）

用户要求先保存当前代码，再检修。检查点 `e68b36c` 已提交在 `codex/no-wall-slowdown`，当时没有推送。下面记录检查点之后的检修；2026-10-15发布保留与100档五件实测一致的修复。

## 已确认的问题

1. 规划与控制的坐标核验不一致。20261014-speed-retest最后停在(-1.652752,-9.917333,yaw2.466183)，最后规划起点(-1.61192,-9.87953,yaw2.4695)。用已安装Nav2 FootprintCollisionChecker复现，规划起点成本0，真实位置成本254；真实车体未碰墙，但带8cm余量的轮廓触碰占用格。最近移动障碍约5.4m外。这能解释该卡点，不能据此把每次失败都归因于定位偏差。
2. 自定义规划器从原始静态地图搜索，界面中的Nav2灰色膨胀区不直接作为搜索代价。旧罚分为`0.03*dt*max(0,1-clearance)`，中心距墙0.5m时只有约1.5%的路段代价，容易选贴边捷径。几何有效不代表有充分的跟踪余量。
3. 加强净距偏好后的第一轮在左移动障碍通道停车约3秒后被其扫到，测试器自动中止。原有固定约0.3秒命令前缀后的制动落点可行，不能证明更早被拒绝指令、立即停车的落点也安全。该轮已保留，不能作为成功验证。

## 修改

- 规划与控制使用共享FrameAlignment，把定位路径映射到仿真真实坐标后检查静态地图与实时移动障碍。搜索后更新实际位置核验，并复核弧段中间位置。
- 增加静态净距软代价`3*max(0,1-clearance/0.85)^2`，同步搜索与启发式。0.85m是车体中心到静态占用格的偏好距离，既不是车边距离，也不是硬通行门槛。窄路代价仍有限；真实车体与8cm轮廓保护保持。
- 正常跟踪预测保持约2秒；制动预测扩展到4秒，分别核验立即、约0.15秒及0.30秒后制动的落点与完整过程，按实时障碍位置预测。不添加整轨道永久遮罩或固定等待目标。
- 增加围绕当前角速度、符合当前角加速度尺度的连续转向候选，避免候选只围绕突然改变曲率的几何指令。
- 拒绝指令记录原因、真实/定位姿态与首次预测冲突位置，便于区分静态/动态问题。

墙边距离限速和RPP代价减速继续关闭。本节导航检修阶段保持2.2m/s、4rad/s、10rad/s²、当时的20N·m、轮子质量和惯量、摩擦、地图、任务颜色顺序；最终发布物理参数随后按用户要求改为1000N·m、驱动/地面摩擦1、ODE约束100；弯道、终点、平滑器与预测保护继续生效。
