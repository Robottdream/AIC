# stable 版本直行与转向提速

修改当前 stable 基础及 /home/polarbear/ws_aic 运行副本，保持任务顺序、
机器人尺寸、质量、轮子摩擦及驱动扭矩。测试使用完整场景中的真实 Nav2 与 Gazebo。

## 配置

| 项目 | 修改前 | 修改后 |
| --- | --- | --- |
| RPP 直行目标上限 | 0.62 m/s | 1.20 m/s |
| 原地转向目标 | 1.50 rad/s | 2.00 rad/s |
| RPP 最大角加速度 | 默认值 | 6.0 rad/s² |
| 控制频率 | 10 Hz | 20 Hz |
| 局部地图更新 | 5 Hz | 10 Hz |
| 平滑器线加/减速度 | 默认值 | +3.0 / −4.0 m/s² |
| 平滑器角加/减速度 | 默认值 | ±6.0 rad/s² |
| 平滑频率 | 默认值 | 30 Hz |
| Gazebo 轮子二次限加速 | 8.0 | 0，由平滑器统一控制 |
| 世界 ODE contact_max_correcting_vel | 10 | 30 |

保留 RPP 曲率减速、近墙代价减速、碰撞预测和终点减速。
速度上限仅在路径和周围空间允许时使用。

物理约束修改沿用本机先前单变量诊断：Gazebo 11.10.2 的 ODE quick 求解器
把 contact_max_correcting_vel 同时用于电机约束，10 对应轮速上限约10 rad/s，
0.065 m 轮半径使底盘实速封顶约0.65 m/s。单纯增加 Nav2 速度不能突破。
本次将该约束调整为30，实测达到1.2 m/s；没有增加5 Nm驱动扭矩。

Gazebo 差速插件的限加速实现会对轮子目标再次处理，设0时直接跟随上游速度；依据
[官方插件源码](https://raw.githubusercontent.com/ros-simulation/gazebo_ros_pkgs/ros2/gazebo_plugins/src/gazebo_ros_diff_drive.cpp)。
平滑器明确限制加减速，避免由两层不同的控制规则叠加决定实际运动。

nav_simple 中旧的交叉预测按固定0.48 m/s估算到达时间，已改为1.2 m/s上限、
3.0 m/s²从静止加速的估计；近处交叉等待仍保留，远处继续由实时 Nav2 避障。
此估计未模拟所有转弯与代价减速，仍是有限预测。

## 同路径运动测试

原点冷启动后按顺序执行5米直行、返回、同位置90度转向和转回。
每段通过真实 /navigate_to_pose；速度与倾角来自 Gazebo 世界里程计。

| 项目（仿真时间） | 修改前 | 修改后 |
| --- | ---: | ---: |
| 5米直行 | 8.976 s | 4.964 s |
| 返回（包含转向） | 12.716 s | 11.152 s |
| 90度转向目标 | 1.360 s | 1.292 s |
| 转回目标 | 4.114 s | 2.040 s |
| 最高底盘线速 | 0.6412 m/s | 1.1995 m/s |
| 四段最大底盘倾角 | 0.02297° | 0.02295° |

直行仿真耗时降低44.7%，墙钟耗时12.41→6.86秒。
四段目标均返回成功。AMCL终点与物理位姿存在差异，真实位置误差约6–16厘米，
部分终点物理朝向误差约0.20 rad，不能把 Nav2 成功等同于精确物理停车。
原有放置前停稳及几何核对仍保留。

短段里程计0.1→0.5 m/s阈值间隔约0.102→0.170秒；该结果不支持
“所有起步加速都更快”的结论。稳定提速主要证据是更高实速和同路径行驶时间，
加速度参数表示命令限值，不是实测值。

记录：log/speed-20261005/baseline 和 fast。
