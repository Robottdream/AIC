## 释放物块与启动通信

带载回归发现释放物块的仿真问题：删除固定吸附约束后，物块在几毫秒内跳动，
分离前符合落点条件、分离后却偏离。原流程已经为关闭重力的货物调用
Gazebo 位姿服务落到板面，现在采用刚刚核验的分离前世界位姿执行同一次落地。
只接受同一物块、2 秒内的快照；板边修正上限仍为 0.11 m。
最终落点仍重新读取并核对目标区与高度，没有放宽成功判据。
新增回归覆盖分离冲击、过期或错误物块快照、过远落点拒绝。

反复冷启动还遇到 Fast DDS 共享内存锁、服务响应超时。
WSL 默认 Fast DDS 启动现在采用 `tools/fastdds_wsl_udp.xml`：本机回环 UDP、
显式初始单播对端、1400 字节消息，避免共享内存锁及大 IP 分片。
用户显式设置的 RMW 或 DDS 配置文件优先，不覆盖这些环境选择。
此默认配置用于同一 WSL 内的 ROS 节点；跨机器 ROS 连接需提供相应 DDS 配置。
依据 [Fast DDS 传输配置](https://fast-dds.docs.eprosima.com/en/2.6.x/fastdds/transport/transport_api.html)
与 [接口白名单](https://fast-dds.docs.eprosima.com/en/v2.6.11/fastdds/transport/whitelist.html)。
独立执行 ROS 测试工具时，本轮同样显式设置该配置文件环境变量。
