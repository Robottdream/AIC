# 雷达动态障碍预测实验（2026-09-30）

本轮在原有 Collision Monitor 与最终速度失联保护之上，加入可选的雷达运动预测。默认关闭，尚不能认定移动障碍碰撞问题已经解决。代码与实测使用 `/mnt/e/workspace/AIC` 源码和 `/home/polarbear/ws_aic` 运行副本。

## 实现

- `/scan` 连续点聚类，使用扫描时间戳对应的 odom TF 消除车辆运动；不读取 Gazebo 模型名或障碍物真值。
- 对 0.35–1.30 m 轮廓匹配轨迹，使用约 0.8 秒历史中的轮廓边界锚点估计速度，要求足够观测时间、低拟合残差和合理速度；用历史表面重叠排除静态物体视角变化。
- 按当前线速度、角速度预测车辆圆弧运动，检查未来 1.8 秒观察到的障碍表面是否进入车体包络及 8 cm 余量；有风险时输出零速度并短暂保持。
- TF/跟踪不可用时退回原有 Collision Monitor；雷达或输入命令失联仍停车。发布 `/navigation/dynamic_guard` 诊断与停车/解除日志。

启用实验配置：

```bash
cd /home/polarbear/ws_aic
AIC_DYNAMIC_GUARD=1 ./ros_competition_start.sh --headless
```

普通一键启动保持预测关闭。新增纯数学模块安装在节点脚本目录，不引入新重依赖。

## 尚未解决

这是恒速预测停车保护，不是按时间规划全局路径，也没有主动逃离被移动障碍持续逼近的位置。部分遮挡、非匀速、短小轮廓及速度估计误差仍可能漏检或误停。真实迎面相遇未通过场景验证，72 个数学静态案例也不能代替复杂实测。完整任务与此前起点、障碍相位不同，52.41 秒不能用于比较成绩提升。
