# 0.35 m/s 移动障碍物验证

基于 `989fd82` 的 stable 2.2 m/s 小车配置，两个移动障碍物目标速度均为 0.35 m/s。

原插件以最大 10 N 的推力追踪速度，实际位移速度受地面接触影响，常态约为
0.1 m/s。当前插件直接设定水平速度，并限制合成速度不超过目标值；保留往返
端点减速、方向切换、轨道偏差修正与碰撞几何。删除不再生效的 force 参数。
该控制会在每个仿真更新周期覆盖水平速度和角速度，不能等同于有限驱动力的
真实物块模型。

2026-10-06 的位移采样中，两个障碍物正常移动段的中位速度分别约为 0.338、
0.340 m/s，最大单秒位移速度约为 0.349 m/s。端点减速与反向时速度更低。

三轮均未触发倾角、位置或高度失稳中止；观测最大底盘倾角分别为
0.0750°、0.0676°、0.0653°。有限轮次不能保证所有障碍相位下均可避障。
更高障碍物速度的试验发生过接触失稳，未采用。

计时范围为解析后的 `/chat` 任务发布至第五次放置确认，不含启动或自然语言
解析。最终位置与高度另外核验；原始日志保存在忽略目录 `log/benchmark/`。
